# Published metric tables

The metric tables behind the paper. They are read by `scripts/evaluate.py` to compare an
external model with the reference generators, and are regenerated by `paper/build_paper_outputs_*.py`
from the Zenodo outputs.

```
results/metrics/
├── pgi_thr10/      Scenario I   (seeds 45, 46, 66, 67; cGAN-cont 65, 66, 67)
├── pgi_pgl/        Scenario II  (seeds 45, 66, 67;     cGAN-cont 65, 66, 67)
└── all_mutants/    Scenario III (seeds 65, 66, 67; continuous variants: positive-class targets)
    └── targeted_p5/   continuous variants at the 5th-percentile KPI target
                       (cVAE-cont / NF-cont seeds 45, 66, 67; cGAN-cont 65, 66, 67)
```

| file | content |
|---|---|
| `metrics_per_seed.csv` | one row per (variant, seed) |
| `metrics_mean_std.csv` | `<metric>__mean`, `__std`, `__count` per variant |
| `metrics_mean_std_pretty.csv` | "mean ± std" strings, as in the paper tables |
| `metrics_full.csv` (Scenario III) | pooled per-perturbation KPI statistics, precision/recall and `mean_KPI_9` (mean KPI over the nine perturbations, non-physical KPIs > 10³ excluded; `n_nonphysical_KPI` counts them) |

The discrete variants are identical in `all_mutants/` and `all_mutants/targeted_p5/`; only the
continuous variants differ.
